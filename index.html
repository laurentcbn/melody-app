Installer Melody
  1. Ouvrez Melody.dmg et glissez Melody dans le dossier Applications.
  2. Ouvrez Melody. macOS indique qu'elle ne vient pas d'un développeur identifié : c'est normal pour une beta.
  3. Ouvrez Réglages système, puis Confidentialité et sécurité, puis cliquez sur « Ouvrir quand même ». Sur macOS 14 ou plus ancien, un clic droit sur Melody puis Ouvrir suffit.
  1. Décompressez Melody-Windows.zip, par exemple dans Documents.
  2. Ouvrez Melody.exe. Windows affiche « Windows a protégé votre ordinateur » : c'est normal pour une beta.
  3. Cliquez sur « Informations complémentaires », puis sur « Exécuter quand même ».
  1. Décompressez Melody-Linux.zip.
  2. Dans le dossier Melody, lancez install.sh : Melody apparaît dans le menu des applications.
  3. Vous pouvez aussi lancer directement le fichier melody.

À faire une seule fois : ensuite, Melody s'ouvre normalement.
