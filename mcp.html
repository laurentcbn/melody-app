Pilotez Melody
avec un assistant.

Melody inclut un serveur MCP. Claude, ou un autre assistant compatible, peut lire votre projet, écrire des clips, régler le tempo et les pistes, et lancer les scènes.

Installer avec Claude Desktop

  1. Installez Melody 0.15 ou plus récent, et ouvrez-la.
  2. Dans Claude Desktop, ouvrez Réglages, puis Développeur, puis « Modifier la configuration ».
  3. Ajoutez Melody dans le fichier, avec le chemin de votre système :
{
  "mcpServers": {
    "melody": {
      "command": "/Applications/Melody.app/Contents/MacOS/melody",
      "args": ["--mcp"]
    }
  }
}
{
  "mcpServers": {
    "melody": {
      "command": "C:\\Users\\vous\\Documents\\Melody\\Melody.exe",
      "args": ["--mcp"]
    }
  }
}
{
  "mcpServers": {
    "melody": {
      "command": "/home/vous/.local/bin/melody",
      "args": ["--mcp"]
    }
  }
}
  1. Redémarrez Claude Desktop. Melody apparaît dans la liste des outils.

Avec Claude Code, une seule commande suffit :

claude mcp add melody -- /Applications/Melody.app/Contents/MacOS/melody --mcp
claude mcp add melody -- "C:\Users\vous\Documents\Melody\Melody.exe" --mcp
claude mcp add melody -- ~/.local/bin/melody --mcp

Essayez par exemple

  • « Passe le projet à 100 BPM et lance la scène 1. »
  • « Ajoute une piste synthé et écris une ligne de basse en La mineur sur la scène 2. »
  • « Baisse le Pad de 3 dB et coupe la Snare. »

Les outils

get_projectLire le tempo, les pistes et les clips de la Session.
set_projectRégler le tempo, le swing et le métronome.
playstopLancer et arrêter la lecture.
add_trackAjouter une piste synthé ou batterie (kick, snare, hi-hat, clap).
set_trackRenommer une piste, régler son volume, son pan, mute et solo.
get_clipwrite_clipLire et écrire les notes d'un clip, en doubles-croches (16 par mesure).
delete_clipEffacer un clip.
launch_cliplaunch_scene · stop_clipsLancer un clip ou une scène à la mesure suivante, ou tout arrêter.

Sur votre ordinateur seulement

L'assistant ne peut piloter Melody que depuis cet ordinateur, et seulement quand Melody est ouverte. Chaque modification s'annule avec ⌘Z (Ctrl+Z). Pour couper l'accès : Préférences, puis Assistant (MCP).

Melody est en beta.
