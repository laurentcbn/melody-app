Assistant (MCP)

Control Melody with an AI assistant

Melody includes an MCP server. Claude, or any other compatible assistant, can read your project, write clips, set the tempo and tracks, and launch scenes.

Set up with Claude Desktop

  1. Install Melody 0.15 or later, and open it.
  2. In Claude Desktop, open Settings, then Developer, then “Edit Config”.
  3. Add Melody to the file, using the path for your system:
{
  "mcpServers": {
    "melody": {
      "command": "/Applications/Melody.app/Contents/MacOS/melody",
      "args": ["--mcp"]
    }
  }
}
{
  "mcpServers": {
    "melody": {
      "command": "C:\\Users\\you\\Documents\\Melody\\Melody.exe",
      "args": ["--mcp"]
    }
  }
}
{
  "mcpServers": {
    "melody": {
      "command": "/home/you/.local/bin/melody",
      "args": ["--mcp"]
    }
  }
}
  1. Restart Claude Desktop. Melody now shows up in the list of tools.

With Claude Code, it takes a single command:

claude mcp add melody -- /Applications/Melody.app/Contents/MacOS/melody --mcp
claude mcp add melody -- "C:\Users\you\Documents\Melody\Melody.exe" --mcp
claude mcp add melody -- ~/.local/bin/melody --mcp

Things to try

  • “Set the project to 100 BPM and launch scene 1.”
  • “Add a synth track and write a bassline in A minor on scene 2.”
  • “Turn the Pad down 3 dB and mute the Snare.”

Tools

get_projectRead the tempo, tracks and clips in Session.
set_projectSet the tempo, swing and metronome.
playstopStart and stop playback.
add_trackAdd a synth or drum track (kick, snare, hi-hat, clap).
set_trackRename a track and set its volume, pan, mute and solo.
get_clipwrite_clipRead and write the notes in a clip, in sixteenth notes (16 per bar).
delete_clipDelete a clip.
launch_cliplaunch_scene · stop_clipsLaunch a clip or scene on the next bar, or stop everything.

Only on your computer

The assistant can only control Melody from this computer, and only while Melody is open. Every change can be undone with ⌘Z (Ctrl+Z). To turn off access, go to Preferences, then Assistant (MCP).
